# ClimaSense AI

Climate intelligence dashboard built with React, Vite, Tailwind CSS, Leaflet, Recharts, and Open-Meteo.

## Run

```bash
npm install
npm run dev
```

Weather and geocoding are real Open-Meteo responses. Risk values are estimated from returned forecast signals. Green-cover, built-up-area, and historical baselines are marked unavailable because no source dataset is connected.
